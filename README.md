# Django Restaurant Site

> A restaurant website built with Django: menu, table booking and orders.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## Features

- Menu with categories and prices.
- Table booking form.
- Order handling.
- Django admin for content management.

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Django, Django REST Framework |
| Database | SQLite |
| Frontend | Django templates, CSS, JavaScript |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/django-restaurant-site.git
cd django-restaurant-site
python -m venv .venv && source .venv/bin/activate
pip install django djangorestframework
python manage.py migrate
python manage.py runserver
```
